# Орбита

Локальная статистика без ежемесячных мучений. **by ilayskol**

Выплаты, суммы для вставки в выплатную форму, отчёты FCN и Excel из выгрузок лидов. Обработка и история — на вашем компьютере.

## Установка на Mac

Требуется **macOS 13 или новее**. Сборки работают нативно, без установки Electron или Node.js.

1. В меню **Apple → Об этом Mac** посмотрите чип: Apple M-серия — **Apple Silicon / arm64**, Intel — **Intel / x64**.
2. Откройте свой **DMG** и перетащите **Орбиту** в **«Программы» (Applications)**.
3. Запускайте приложение из «Программ», затем извлеките образ диска. Настройки, импорт и отчёты работают так же, как в Windows/Linux; доступны **Cmd+C / Cmd+V / Cmd+A**.

**Первый запуск:** Mac-сборка имеет ad-hoc подпись, но **не сертификат Developer ID и не нотариализована Apple**. macOS может заблокировать открытие. Если доверяете источнику, после попытки запуска откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** и подтвердите запуск Орбиты. Не отключайте защиту всей системы. На корпоративном Mac доступ может ограничивать администратор. [Инструкция Apple](https://support.apple.com/102445).

Настройки и библиотека: `~/Library/Application Support/PIMOrbit`. При обновлении закройте Орбиту и замените приложение в «Программах»; папка данных находится отдельно. Настройки между разными компьютерами автоматически не синхронизируются.

## Настройка

[![Орбита — настройка офферов, вставка порядка из таблицы и работа с отчётами](images/Orbita-1.8.8-Setup-Guide.png)](https://github.com/ilayskol/Orbita/releases/download/v1.8.8/Orbita-1.8.8-Setup-Guide.png)

1. **Собственные вебы:** введите свои WM ID через запятую. Их выплаты остаются в базе, но исключаются из внешних выплат. Статусы `approved, 1, Одобрена, Payout` и десятичная запятая уже выбраны.
2. **Офферы:** добавьте `ID;название;компания;страна`. ID берите из колонки «Оффер» в выгрузке. Страна — RU или KZ. Для отчёта FCN компания должна называться `FCN`. У оффера в разных компаниях могут быть разные ID.
3. **Порядок формы:** нажмите **«Вставить строки из таблицы»**. Скопируйте только свой блок из Excel или Google-таблицы, вставьте его и нажмите **«Проверить строки»**. Сверьте число строк, страны и последовательность в предпросмотре, затем нажмите **«Применить этот порядок»**. Непонятные строки, чужие владельцы и дубли требуют исправления.
4. **Сохранение:** кнопка «Сохранить настройки» закреплена сверху. При уходе с изменениями выберите «Сохранить и перейти», продолжение редактирования или явную отмену. Для старого набора из двух статусов нажмите «Стандартные статусы» и сохраните. Регистр букв не важен.

**Ручной ввод** тоже доступен: `оффер;компания;WM ID;страна`, сверху вниз как в вашей форме, включая нулевые строки. После ручных изменений нажмите **«Сохранить настройки»**.

Полупрозрачный текст и кнопка **«Заполнить примером»** содержат вымышленные названия и номера. Они показывают формат — замените их своей схемой. ID офферов автоматически из названий не создаются.

## Каждый месяц

**Импорт → Выплаты → выберите страну → Скопировать суммы → вставьте в свой столбец.** Россия и Казахстан копируются отдельно. До вставки сверяйте порядок и число строк.

**Отчёт FCN:** сводка для чата и отдельный Excel с лидами. Названия офферов и выбранный месяц попадают в короткий отчёт. Отсутствие строк в выгрузке не подтверждает отсутствие лидов в системе.

**Новая выгрузка** начинает другой отчёт. Доступная кнопка добавления файла дополняет текущий; совместимые повторы исключаются.

**История** показывает отчёт по сохранённым тогда правилам, не перезаписывая текущие настройки. Для пересчёта открытой выгрузки есть кнопка «Пересчитать по текущим настройкам». Исходная запись истории остаётся прежней.

Месяц в «Базе лидов» фильтрует базу отдельно. Выплаты и FCN ограничиваются выбранным месяцем только при включённом фильтре в настройках. Для пограничных дат проверьте часовой пояс выгрузки.

## Данные и совместимость

Интернет для работы не нужен. Клиентские выгрузки и личная история в установщик не включены. Локальная история не зашифрована: не передавайте её вместе с программой и не публикуйте свои отчёты.

Windows и Linux x64; macOS — отдельные нативные сборки arm64 и x64. На Windows проверен рабочий сценарий. На Linux проверены сборка и запуск в тестовой среде; полный сценарий на обычном Linux-десктопе отдельно не проверялся. Mac-пакеты собираются и проверяются на macOS 15 (Intel) и macOS 26 (Apple Silicon): подпись, архитектура, запуск приложения, настройки, импорт, Excel и история. Пользовательский первый запуск через Gatekeeper на физическом Mac отдельно не проверялся.
